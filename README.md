# ATELIER SOLSTICE — Architectural Monoliths & Spatial Ceramics

> An Awwwards-inspired architectural editorial digital experience celebrating Kyoto & Copenhagen minimalism, monolithic residences, and natural daylight.

## Key Features

- **Real-Time Dynamic Sunlight Simulator:** An interactive 3D heliodon slider (06:00 to 20:00) that recalculates sun azimuth, elevation, and color temperature in real time, casting soft directional shadows across the ceramic sculpture and travertine plinth.
- **Material Alchemy Studio:** Real-time tactile mineral switching between Kyoto Fired Terracotta, Raw Roman Travertine, Obsidian Basalt, and Bianco Carrara Marble.
- **Architectural Monographs:** Editorial lookbook exploring coastal monoliths in Kamakura, Bornholm, and Arashiyama.
- **Procedural Zen Bowl Acoustics:** Web Audio API synthesis generating meditative singing bowl acoustic overtones.
- **Lenis Inertial Scrolling:** Soft editorial scroll pacing with tactile grain overlays.

## Tech Stack

- **Framework:** React 18, Vite, TypeScript
- **3D & Shadows:** Three.js (r173) with PCFSoftShadowMap and ACESFilmic tone mapping
- **Styling:** Tailwind CSS, Custom Wabi-Sabi Design Tokens
- **Audio:** Web Audio API procedural synthesis
- **Smooth Scroll:** Lenis Smooth Scroll
- **Icons:** Lucide React

## Getting Started

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build production bundle
npm run build

# Preview production build
npm run preview
```
